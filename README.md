# UnderstoryMyrtle

UnderstoryMyrtle enables real-time data processing, auto-scaling for horizontal load, and integrates with cloud database APIs for scalable performance.

UnderstoryMyrtle is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/UnderstoryMyrtle.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

UnderstoryMyrtle is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
